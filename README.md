# Student Management System

A GUI-based Student Management System developed using Python.

## Features

- Add student records
- View student records
- Search students by roll number
- Update student information
- Delete student records
- CGPA calculation
- Percentage calculation
- Grade calculation
- SQLite database
- Student performance graph
- User-friendly graphical interface

## Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib

## Project Description

The Student Management System is a desktop application developed using Python and Tkinter.

It allows users to add, view, search, update, and delete student records. The application stores student information using an SQLite database.

The system also calculates percentage and grade based on CGPA and provides a performance graph using Matplotlib.

## How to Run

1. Install Python.
2. Install Matplotlib:

pip install matplotlib

3. Open the project folder in VS Code.
4. Run the following command:

python student_management_gui.py

## Database

SQLite is used to store student records.

The database file is created automatically when the application runs.
